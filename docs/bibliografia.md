# Bibliografia

## Desenvolvimento

### Model Context Protocol (MCP)

O desenvolvimento utiliza o **Model Context Protocol (MCP)** como camada intermediária entre o modelo de linguagem e os serviços do backend. O servidor MCP é responsável por consumir as APIs disponibilizadas pelo backend e fornecer as informações necessárias ao modelo de linguagem.

### Google Fact Check Tools API

Documentação oficial da API do Google Fact Check Tools, utilizada para consulta de informações relacionadas a verificações de fatos.

- [Google Fact Check Tools API — Documentação oficial](https://developers.google.com/fact-check/tools/api/reference/rest/v1alpha1/pages?hl=pt-br)

## Bases de dados sobre Fake News

### Kaggle — Fake News Detection Datasets

Conjunto de dados disponibilizado na plataforma Kaggle para pesquisas e desenvolvimento de modelos relacionados à detecção de notícias falsas.

- [Fake News Detection Datasets — Kaggle](https://www.kaggle.com/datasets/emineyetm/fake-news-detection-datasets)

### Fake News Datasets — Media Futures

Repositório de conjuntos de dados relacionados à detecção e análise de notícias falsas, disponibilizado pelo projeto Media Futures.

- [Fake News Datasets — Media Futures](https://mediafutureseu.github.io/fakenewsdatasets.html)

### Awesome Fake News Datasets

Lista organizada de conjuntos de dados relacionados à detecção, classificação e análise de notícias falsas.

- [Awesome Fake News Datasets — GitHub](https://github.com/thcheung/awesome-fake-news-datasets)
