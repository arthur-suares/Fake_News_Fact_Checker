## Metodologia MOSCOW


| Must have | Should have | Could have | Wont have |
| :--------:| :----------:| :---------:| :--------:| 
| **Banco de Dados Estruturado (Postgree): **Para armazenar os inputs e as classificações geradas pelo modelo, permitindo futuros retreinos. </br> </br> **Integração com API de Checagem (Google):** O motor de validação da verdade factual que alimenta nosso modelo. </br> </br>  **Interface do Usuário (UI) e Questionário:** O formulário de entrada para coleta da notícia e das respostas comportamentais. </br> </br>  **Modelo de Classificação de Perfis (IA):** Implementação de um modelo de Machine Learning (Random Forest) para classificação Identifica o nível de viés de confirmação do usuário. Ele precisa cruzar três variáveis principais:<ul><li>A expectativa do usuário (Acha que é verdadeiro/falso).</li><li>O alinhamento da notícia (Condiz ou não com suas crenças).</li><li>A verdade factual (Veredito da API do Google).</li></ul> | **Dashboard de Explicabilidade (XAI):** Um painel simples (usando SHAP ou LIME, por exemplo) para que possamos entender por que o modelo classifica o usuário em determinado perfil. </br> </br> **Processamento de Linguagem Natural (NLP) no Link:** Um modelo de NLP básico para extrair palavras-chave ou o tom da notícia enviada, adicionando mais uma feature (variável) para enriquecer nosso classificador de perfis. </br> </br> **Feedback Educativo ao Usuário:** Usar a classificação gerada pela IA para devolver uma mensagem personalizada (ex: "Notamos que você tende a acreditar em notícias falsas quando elas se alinham à sua visão política. Cuidado com o viés de confirmação!").</br> </br> | **Sistema de Login:** Para rastrear o comportamento do mesmo usuário ao longo de múltiplas consultas e criar uma série temporal do seu viés. </br> </br> | **Pipeline de MLOps (Retreinamento Contínuo): **Um script que reavalie os pesos do modelo conforme a base de dados cresce e novos padrões de viés de confirmação emergem. </br> </br> **Modelo Próprio de Fact-Checking: **Continuaremos dependendo da API do Google para a verdade factual, focando nosso esforço de IA 100% no comportamento humano, e não na checagem do texto em si.
